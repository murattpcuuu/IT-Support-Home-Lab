# IT Support Home Lab

## About This Project
This repository documents my hands-on IT Support learning journey.

## Lab Environment
- Host OS: Windows 11
- Virtualization: VMware Workstation Pro 17.6
- Guest OS: Windows 11 25H2
- RAM: 4 GB
- CPU: 2 Cores
- Network: NAT

## Completed Labs

### 1. Windows 11 Virtual Machine Setup
- Installed Windows 11 in VMware.
- Configured virtual hardware.
- Installed VMware Tools.

### 2. Basic Network Troubleshooting
- Used ipconfig and ipconfig /all.
- Checked IP configuration.
- Tested connectivity with ping.
- Investigated DNS using nslookup.
- Compared default DNS with Google DNS (8.8.8.8).
